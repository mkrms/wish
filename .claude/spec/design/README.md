# 機能外仕様: デザイン方針（design）

Wish のデザイン方針の所在。**デザインの一次ソースは Claude Design モックアップ**であり、
実装はそれを忠実移植している。

## デザインの出典
- `project/Wish.dc.html` … 採用モックアップ（実装の出典）。挙動・レイアウト・語彙の正はこれ。
- `project/Wish (dark v1).dc.html` / `project/Wish 方向性.dc.html` … 検討バリエーション。
- `chats/`・`.claude/chats/` … デザイン確定までの会話ログ（意図の出典）。

## 守るべき方針（要点）
- **ナビ語彙**は「今日 / 受信トレイ / メモ / ダッシュボード / 完了済み / 設定」。
- **CDN 非依存・オフライン完全動作**。フォント・アイコン（Roboto / Material Symbols）は同梱。
- **「今日」は実時刻ベース**、サンプルは相対日付生成で「いつ開いてもデザイン通り」に見せる。
- **ダッシュボードは完了率・進捗率・フェーズを出さない**（自分視点の4指標で表現。decisions-log D-005）。

> 新しいデザイン判断が出たら、ここに方針を追記し、必要なら decisions-log にも残す。
